# 二、i18n 国际化规范

> 返回 [SKILL 主入口](../SKILL.md)。

## 2.1 目录结构

```
src/i18n/locales/
├── zh-CN/  ├── common.json  ├── sidebar.json  ├── aiBudget.json  …  └── index.ts
├── en-US/  ├── common.json  ├── sidebar.json  ├── aiBudget.json  …  └── index.ts
└── ja-JP/  ├── common.json  ├── sidebar.json  ├── aiBudget.json  …  └── index.ts
```

每种语言一个目录，按**顶级功能模块**拆 JSON 文件，`index.ts` 聚合导出整个 locale。

## 2.2 翻译文件结构（嵌套键，按模块分组）

```json
{
  "common": { "save": "保存", "cancel": "取消", "loading": "加载中..." },
  "sidebar": { "dashboard": "数据看板", "aiBudget": "AI 预算" },
  "aiBudget": { "title": "AI 预算", "tabs": { "overview": "总览" } }
}
```

实际拆分时，每个顶级模块单独一个 JSON 文件（`common.json` / `sidebar.json` / `aiBudget.json` …），由 `index.ts` 聚合：

```ts
import module0 from './common.json';
import module42 from './aiBudget.json';
const locale = { "common": module0, /* … */ "aiBudget": module42 } as const;
export default locale;
```

## 2.3 使用方式

```tsx
import { useLanguage } from '@/contexts/LanguageContext';

function MyComponent() {
  const { t } = useLanguage();
  return <span>{t('common.save')}</span>;
}

// 变量插值
<span>{t('common.totalRecords', { total: 100 })}</span>
<span>{t('common.pageInfo', { current: 1, total: 10 })}</span>
```

`t(key, params?)` 支持 `{paramName}` 占位插值（内部对每个 param 执行 `value.replace(/\{key\}/g, …)`）。

## 2.4 语言切换

```tsx
const { setLanguage, language, availableLanguages } = useLanguage();
setLanguage('zh-CN'); // 'zh-CN' | 'en-US' | 'ja-JP'
```

## 2.5 新增 key —— 改一处要改四处 ★

**这是最容易漏的地方。** 新增任意翻译 key，必须：

1. 在 `zh-CN/<模块>.json` 加中文。
2. 在 `en-US/<模块>.json` 加同路径英文。
3. 在 `ja-JP/<模块>.json` 加同路径日文。
4. 若**新增了一个模块 JSON 文件**（而非往已有文件加 key），还要在**三个** `index.ts` 各加一行 `import` + locale 聚合项：

```ts
// 三个 index.ts 都要改
import module42 from './aiBudget.json';
const locale = {
  // …
  "gsCoreAiMcpServer": module41,
  "aiBudget": module42        // ← 新增模块的聚合
} as const;
```

规则补充：
- 遵循现有模块划分，保持 key 前缀与文件名一致。
- 变量用 `{}` 包裹，如 `{total}`、`{current}`。
- **三语言的 leaf key 必须逐字段一一对齐**，漏一个就会在该语言下显示原始 key（线上漏翻译）。

### 提交前自查命令

```bash
node -e "
function keys(o,p=''){let r=[];for(const k in o){const n=p?p+'.'+k:k;
 (o[k]&&typeof o[k]==='object'&&!Array.isArray(o[k]))?r=r.concat(keys(o[k],n)):r.push(n);}return r;}
const zh=keys(require('./src/i18n/locales/zh-CN/aiBudget.json')).sort();
const en=keys(require('./src/i18n/locales/en-US/aiBudget.json')).sort();
const ja=keys(require('./src/i18n/locales/ja-JP/aiBudget.json')).sort();
console.log('zh-en diff:',zh.filter(k=>!en.includes(k)).concat(en.filter(k=>!zh.includes(k))));
console.log('zh-ja diff:',zh.filter(k=>!ja.includes(k)).concat(ja.filter(k=>!zh.includes(k))));
"
```
三个 diff 都为空才算同步完成。

## 2.6 变量插值用 `t(key, params)`，不要手写 `.replace`

```tsx
// ✅ 推荐
t('aiBudget.diagnostic.resetSuccess', { count: res.deleted })   // "已清除 5 条用量记录"
// ⚠️ 不推荐（能用但脱离规范）
t('aiBudget.diagnostic.resetSuccess').replace('{count}', String(res.deleted))
```

## 2.7 稳定标识符不要走 i18n ★

凡是用作 React `key`、`switch`/状态判断、菜单展开状态的标识符，**必须用不随语言变化的常量 id**，不要用 `t(...)` 的返回值当 key（详见 [§09 侧边栏 id 重构](./09-sidebar-navigation.md)）。
